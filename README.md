# Lidong Xie — Personal CV

A simple personal CV website with education, seven technical projects, professional experience, contact links, and a downloadable CV.

## Technology

- HTML for the page content and section links.
- CSS for typography and responsive desktop/mobile layouts.
- JavaScript for the active navigation section and footer year. The CV and links also work without JavaScript.

## Editing

Edit text and project links in `index.html`, appearance in `styles.css`, and navigation behaviour in `script.js`. Replace `Lidong-Xie-CV.pdf` to update the CV download and `portrait.jpg` to update the photo. The font files are self-hosted; their notices are in `FONT-LICENSES.txt`.

## Hosting

This static site needs no build step. GitHub Pages can serve it from the main branch and repository root.
